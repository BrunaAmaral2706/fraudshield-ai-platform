## Descrição técnica (LinkedIn Featured / About)

FraudShield é uma **plataforma de fraud intelligence** construída com padrões de fintech enterprise: observability em tempo real, scoring de risco explicável, detecção de anomalias com Isolation Forest e arquitetura lakehouse Medallion.

A solução integra **frontend React**, **API analítica Node.js** e **pipeline ML Python** em um único sistema de monitoramento antifraude — com KPIs executivos, alertas dinâmicos por severidade, AI Monitoring e tabela operacional com drill-down por transação.

Projetada para demonstrar competências em **risk analytics**, **data engineering**, **machine learning aplicado** e **SaaS enterprise UI**.

**Stack:** React 19 · Vite · Tailwind · Recharts · Zustand · Node.js · Express · Python · Isolation Forest · Random Forest · Lakehouse

**Repositório:** https://github.com/BrunaAmaral2706/fraudshield-ai-platform

## Post LinkedIn (copiar e publicar)

---

**Fraude em pagamentos não é um problema de dashboard — é um problema de observability.**

Em fintech, equipes de risco precisam enxergar padrões, scores e anomalias **antes** que viram prejuízo. Por isso construí o **FraudShield** — uma plataforma enterprise de fraud intelligence.

**O problema**
Transações fraudulentas geram perdas bilionárias, mas muitas operações ainda reagem tarde demais — sem scoring unificado, sem alertas priorizados e sem visibilidade ML em produção.

**A solução**
Uma plataforma completa de **fraud analytics + AI monitoring**:

→ KPIs executivos e fraud rate em tempo real
→ **Risk Engine** multi-fator (amount, velocity, category, suspicious hours)
→ **Isolation Forest** para anomaly detection
→ AI Monitoring com fraud probability e anomaly timeline
→ Alertas dinâmicos por severidade (LOW → CRITICAL)
→ REST API analítica com filtros globais sincronizados

**Stack**
React 19 · Node.js · Express · Python · Lakehouse Medallion · Zustand · Recharts · Isolation Forest

**Impacto técnico**
750 transações fraudulentas analisadas · 12+ endpoints · pipeline ML com inferência em startup · arquitetura desacoplada pronta para escala
