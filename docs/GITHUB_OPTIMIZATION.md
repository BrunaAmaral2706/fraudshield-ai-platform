## Professional Commit Convention

| Prefix | Uso | Exemplo |
|--------|-----|---------|
| `feat:` | Nova funcionalidade | `feat: add AI monitoring risk heatmap` |
| `fix:` | Correção de bug | `fix: resolve period filter empty state` |
| `docs:` | Documentação | `docs: enterprise README and LinkedIn positioning` |
| `refactor:` | Refatoração sem mudança de comportamento | `refactor: extract risk scoring to service layer` |
| `perf:` | Performance | `perf: optimize CSV parsing with stream` |
| `chore:` | Manutenção | `chore: update gitignore for parquet files` |
| `test:` | Testes | `test: add API validation script` |

### Commits sugeridos para esta sessão de polimento
